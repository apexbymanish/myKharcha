# Localised posts

These convert better than the English channels for this app, because the store
listing is already translated into these languages and almost nothing else in
the category is. Post as yourself, in first person; a translated press release
reads as one and gets ignored.

## A note on posting

Do not post the same text to five places on one day. Space them a week apart,
and reply to every comment on each — a thread with the maker answering
questions outlives the post itself, and is what people find when they search
later.
